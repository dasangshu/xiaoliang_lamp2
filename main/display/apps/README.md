# 应用模块开发约定

应用中心采用“注册表 + 统一设计系统 + 独立业务页面”的结构：

- `app_registry.*`：应用名称、图标、文案、标签、主题色与动作入口。
- `app_theme.h`：全局颜色、圆角、间距、阴影和交互状态。
- `lcd_display.cc`：当前各业务页面及事件路由，后续可按业务逐个迁入本目录。

新增应用时：

1. 在 `AppKind` 增加类型，并在 `kModules` 注册应用。
2. 使用 `app_theme.h` 的设计令牌和 `StyleCard` / `StylePressable`，不要写重复的视觉常量。
3. 在 `OnAppModuleClicked` 只增加路由，业务状态与页面实现放在独立模块。
4. 触控区域不小于 `kTouchTarget`，卡片标题、摘要和状态标签必须齐全。

产品界面原则：温暖、克制、可信；主操作突出，次要信息降噪；所有应用保持一致的导航、卡片和反馈语言。
